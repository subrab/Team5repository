# D4 Focused POC / validation: jury lens

**Jury marks:** 20 of 100 · **Length:** about 1 page

**What done looks like (workbook):** The evidence answers one meaningful architecture question. A full application is not expected.

The reviewer also checks that:
- State the one architecture question tested and why it was the part of the solution that most needed evidence before recommending it.
- Describe what was built or run, with which tool and model, within the 60-75 minute time-box.
- Describe the method and the synthetic test data.
- Report results ONLY from the owner's notes. If no results are in the notes yet, write 'Pending: not yet run' and invent nothing.
- State what was learned, what remains unproven, and whether the D2 decision still holds.
- The POC was built spec-first and its traceability matrix (TRACEABILITY.md) shows Requirement -> Spec -> Rule -> Code -> Test with passing tests (Chennai Manifesto).
